# Консольный трекер прочитанных книг на Python

Простое учебное консольное приложение для ведения учета прочитанной литературы, анализа личной статистики и управления данными через формат JSON.

## Функционал программы

Программа предоставляет текстовое интерактивное меню со следующими возможностями:

1. **Добавить книгу**: Пользователь вводит автора, название, оценку (от 1 до 5) и дату прочтения. 
   - *Защита от дубликатов*: Программа автоматически проверяет базу данных. Нельзя добавить книгу одного и того же автора с одинаковым названием дважды (проверка нечувствительна к регистру букв).
2. **Показать все книги**: Выводит упорядоченный нумерованный список всех сохраненных книг с детальной информацией.
3. **Показать среднюю оценку**: Рассчитывает средний балл по всей библиотеке на основе выставленных оценок.
4. **Статистика по авторам**: Группирует книги по авторам, отображая количество прочитанных книг у каждого автора и их среднюю оценку.
5. **Удалить книгу**: Позволяет выбрать книгу по ее порядковому номеру из списка и безвозвратно удалить из базы.
6. **Выход**: Корректное завершение работы приложения.

## Технологический стек и архитектура

- **Язык программирования**: Python 3
- **Хранение данных**: Локальный файл `books.json` (формат JSON). Данные автоматически считываются при запуске программы и перезаписываются при любом изменении (добавление или удаление).
- **Структура данных книги**:
  - `author` (строка) — имя/фамилия автора.
  - `title` (строка) — название произведения.
  - `rating` (целое число от 1 до 5) — персональная оценка.
  - `date_read` (строка) — дата завершения чтения.

## Особенности реализации

- Код разбит на изолированные функции с четкой зоной ответственности (`load_books`, `save_books`, `add_book`, `list_and_stats`, `delete`).
- Внедрена валидация пользовательского ввода (защита от пустых строк, проверка диапазонов чисел и обработка исключений `ValueError`).
- Для вывода списков применяется функция `enumerate()`.
- Использована конструкция `if __name__ == "__main__":` для безопасного запуска главного модуля.
